# Support

Thanks for using Contentine Create. Here's where to go:

- **Questions / ideas / "how do I…":** open a [GitHub Discussion](https://github.com/BeyondITL/contentine-create/discussions) (enable Discussions on the repo if this 404s).
- **Bugs:** open an [issue](https://github.com/BeyondITL/contentine-create/issues/new/choose) using the bug template, with a reproduction and your browser/OS (and whether WebGPU is available).
- **Feature requests:** use the feature template.
- **Security:** see [SECURITY.md](SECURITY.md) — report privately, not in a public issue.
- **Contributing:** [CONTRIBUTING.md](CONTRIBUTING.md) and [ROADMAP.md](ROADMAP.md).

This is a community prototype maintained on a best-effort basis. Clear, reproducible reports get help fastest.
